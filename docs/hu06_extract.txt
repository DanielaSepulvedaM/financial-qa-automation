 Descripción  
Como QA automation, quiero automatizar pruebas de API del módulo de pago de crédito, para validar de forma repetible el comportamiento del mockAPI y asegurar la cobertura de los escenarios funcionales principales del proyecto.
Contexto:
El proyecto cuenta con un mock API que simula el backend del módulo de pago de crédito. A partir de los requerimientos, el diseño funcional y los
casos de prueba definidos, se requiere automatizar los escenarios más importantes del flujo para validar el comportamiento del servicio de forma
controlada y reutilizable.
Objetivo:
Automatizar pruebas de API para los flujos principales del módulo de pago de crédito, incluyendo consulta de crédito, registro de pago exitoso y
validaciones de pago inválido.
Alcance:
Crear pruebas automatizadas para consulta de crédito
Crear pruebas automatizadas para pago exitoso
Crear pruebas automatizadas para pago inválido
Reutilizar un cliente HTTP común para los endpoints del mock API
Ejecutar las pruebas localmente con pytest
Escenarios a automatizar:
Consulta de crédito existente
Consulta de crédito inexistente
